# myproj

一个用于**短视频内容质量审核**的简化版 Agent 原型（Python）。

目标：
- 维护商业生态（反垃圾营销、虚假承诺、异常引流）
- 维护平台安全（高风险文本线索）

## 1) 快速开始

```bash
python3 content_audit_agent.py
```

你会看到示例内容的审核结果：
- `allow`: 通过
- `human_review`: 进入人工复审
- `reject`: 拒绝/下架

## 2) 设计思路（MVP）

当前版本采用**可解释的规则引擎**，适合先搭建最小可用系统：

1. 输入：文本 + 用户行为信号
2. 检测：
   - 安全风险模式（如暴力威胁、违法交易线索等）
   - 商业生态模式（如私域引流、夸大宣传、欺诈促销词等）
3. 风险加权打分
4. 按阈值输出决策（通过 / 人审 / 拒绝）

## 3) 文件说明

- `content_audit_agent.py`: 核心审核 Agent（规则、打分、决策）

## 4) 下一步建议

你后续可以把这个 MVP 逐步升级成线上系统：

- 将规则命中替换为多模型：
  - 文本安全分类模型
  - 商业合规分类模型
  - 账户风险评分模型
- 引入置信度校准与分层队列（高风险秒级拦截，中风险入复审）
- 增加审核运营闭环：
  - 人审结果回流训练数据
  - 规则/模型 A/B 测试
  - 指标监控（误杀率、漏放率、复审通过率）
